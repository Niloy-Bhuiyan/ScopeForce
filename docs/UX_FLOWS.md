# UX flows

Intake → Structure idea → CampusLink home → Clarify → Scope → Architecture → Engineering Graph → Build → Proof → Blast Radius → Handoff.

Intake accepts source context and shows index state. Clarification explains engineering impact and cites sources. Graph selection opens a contextual inspector. Build exposes the collision before progress; “Reorder safely” creates an explicit dependency. Proof offers a drift repair task. Blast Radius creates an impact plan. Handoff exports the project model, trace, risks, and truth labels.
