# Product requirements

## Core outcome

A user can bring rough notes into ScopeForce, inspect grounded questions and structured requirements, navigate the Engineering Graph, safely simulate build orchestration, evaluate evidence, repair drift, plan an impacted change, and export a meaningful build package.

## Acceptance boundaries

- Every primary view uses the same CampusLink entities and relationships.
- Selecting a graph node highlights upstream and downstream lineage.
- The build simulation never presents itself as live provider execution.
- AI answers cite retrieved source IDs and express uncertainty with insufficient context.
- Repair and impact actions mutate application state and create notifications.
- The product is usable at desktop and mobile widths.
