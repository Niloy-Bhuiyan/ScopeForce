# Design system

The references establish a warm editorial system. Canvas `#f6f2eb`, paper `#fffdf9`, ink `#17232c`, slate `#667079`, paprika `#cf4d2d`, moss `#376b50`, amber `#cf8227`, blue `#5777a8`, and lilac `#6c6197` are the core tokens. Serif display type is paired with a readable sans body. Graph kinds reuse restrained semantic colors.

Spacing follows a 4/8/12/16/24/32/48/64 scale. Borders are warm gray, radii are 10/16/22, and shadows are diffuse and shallow. Motion uses 160–280ms ease-out transitions only for state changes. Focus rings use paprika with a visible offset; reduced-motion preferences disable transitions.
