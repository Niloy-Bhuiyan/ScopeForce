# Test strategy

TypeScript tests cover lineage, impact classification, collisions, safe reordering, and build progress. Python tests cover health, chunk/source metadata, relevant retrieval, irrelevant and empty context, schema validation, malformed provider output, provider errors, and prompt grounding. Static gates cover ESLint, strict TypeScript, Ruff, and production builds. Browser QA covers all primary routes, console errors, desktop/mobile composition, graph interaction, and production deep links.
