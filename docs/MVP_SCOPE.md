# MVP scope

Included: intake by text/files/voice, project home, clarification, structured scope, architecture, Engineering Graph, deterministic build orchestration, predicted collision resolution, proof, drift repair, blast radius, handoff export, integrations, local auth screens, settings, plan UI, notifications, and the real configurable RAG backend.

Excluded: durable accounts, payments, production vector persistence, real coding-agent execution, repository mutation by providers, and organization-grade authorization. These are deliberately excluded to keep the vertical slice defensible.
